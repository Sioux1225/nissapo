# 日報サポート（ホーム画面の名前：日サポ）

軽貨物ドライバー向けの、運転日報・点呼記録簿アプリ（PWA）。
出発するときに「乗務前点呼」、帰ってきたときに「乗務後点呼」をタップして記録するだけで、毎日の運転日報と点呼記録簿ができる。

- 費用：利用者・会社とも 0円（サーバーなし。データは各自のスマホの中だけに保存）
- 事務所への提出：「書き出し・共有」から Excel・PDF・CSV を作り、LINE・メールで送る
- Excel は事務所の年間ブック（`{年}/{営業所}/{年}{運転者名}.xlsx`）と同じ形
  - シート：運転日報1月〜12月 → 点呼記録簿1月〜12月（1年分のとき）
  - 運転日報は 1日＝4行目、点呼記録簿は 1日＝5行目。列も同じ並び
  - 終了時走行距離は `=SUM(G,I)` の式、時刻は `h:mm`

## 構成

ビルド作業は不要。外部のプログラム（ライブラリ）も使っていない。

| ファイル | 役割 |
|---|---|
| `index.html` / `css/app.css` | 画面の土台とデザイン（確サポと同じ配色） |
| `js/app.js` | 画面（はじめての設定・ホーム・入力・一覧・書き出し・設定） |
| `js/model.js` | 記録の形・初期値・走行距離の引き継ぎ・帳票の行の組み立て・CSV |
| `js/xlsx.js` | Excel（.xlsx）を作る（zip も自前） |
| `js/accident.js` | 事故の記録（輸送安全規則 第九条の二の8項目・3年保存）と、その Excel・CSV |
| `js/photo.js` | 事故の写真（縮小して端末内に保存・バックアップ用の変換） |
| `js/oil.js` | オイル交換（前回からの走行距離・3,000〜4,500km のお知らせ・5,000km までに交換・エレメントは2〜3回に1回（10,000〜15,000km）） |
| `js/expiry.js` | 車検・運転免許証の期限のお知らせ（60・30・14・7日前と期限切れ） |
| `js/sales.js` | 売上表（前払い・月報）：佐川急便は配達個数×単価（営業所を選ぶと単価表の単価）、日極の案件は乗務日×日極。月初めから今日までの合計。単価表を更新したら `OFFICES` と `PRICE_TABLE_DATE` を直す |
| `js/pdf.js` | 帳票を画像に描いて A4横の PDF にする |
| `js/db.js` | 端末内データベース（IndexedDB） |
| `sw.js` / `manifest.webmanifest` | オフライン対応・ホーム画面への追加 |

## 開発

```bash
node tools/serve.mjs
```

→ http://localhost:8766 をブラウザで開く（`?nosw` を付けるとオフライン用の保存をしない）。

```bash
npm test
```

## 公開（GitHub Pages）

確サポと同じ。このフォルダを GitHub のリポジトリに push し、Settings → Pages で `main` / `/(root)` を選ぶ。

## 更新するとき

`sw.js` の `VERSION` と `js/app.js` の `APP_VERSION` を上げて push する（例：0.4.1 → 0.4.2）。
→ 利用者がアプリを開いたとき（または別のアプリから戻ってきたとき、開いている間は30分ごと）に新しい版が届き、「新しいバージョンがあります［更新する］」が表示される（データは消えない）。入力の途中で「更新する」を押したときは、入力中の内容が消えることを確認してから読み込み直す。
